The headline: the retrieval baseline A is identical across both models (embeddings don't use the chat LLM) — so every change is in the generated arm E. On gpt-4o-mini, E was significantly worse than plain chunks (Evidence Recall@5 0.349, Δ−0.140, p=0.001). Swapping to gpt-5.4-mini lifted E to 0.475 (Δ−0.015, p=0.70) — a statistical tie. The better model wrote better questions, turning a real loss into parity. Answer Exact-Match rose for both conditions (A 0.812→0.928, E 0.710→0.884) because the answer LLM also improved.

Closed 10-article pilot (n=69) — not full-corpus MultiHop-RAG. gpt-4o-mini figures are from the initial run of this same pipeline; gpt-5.4-mini figures are the current on-disk results. Answer-EM baseline differs between models because the answer generator is the LLM; the retrieval baseline does not.
