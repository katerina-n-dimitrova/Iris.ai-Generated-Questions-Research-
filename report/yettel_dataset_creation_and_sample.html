How the Yettel Bulgaria dataset was created

A synthetic Bulgarian multi-hop RAG benchmark built from publicly available Yettel Bulgaria corporate pages. The documents contain real public prose; GPT-5.4-mini generated the evaluation questions, answers, and evidence links.

Simple pipeline

DiscoverRead the public Yettel corporate sitemap and download each listed HTML page.
CleanExtract main article prose and remove navigation, headers, footers, tables, figures, forms, media, and scripts.
FilterKeep unique Bulgarian pages containing 1,500–5,000 cl100k_base tokens and deterministically select 340.
ChunkSplit documents into 1,024-token chunks with 128-token overlap and assign stable IDs.
Create evaluation QAGroup related documents and generate Bulgarian inference, comparison, temporal, and unanswerable questions.
Validate and labelRequire verbatim evidence, map it to canonical document/chunk IDs, and reject invalid or duplicate outputs.

Important: This is a research dataset created from Yettel’s public pages. It is not an official dataset released or endorsed by Yettel. The recorded dates come from sitemap last-modified values and are not necessarily publication dates.
