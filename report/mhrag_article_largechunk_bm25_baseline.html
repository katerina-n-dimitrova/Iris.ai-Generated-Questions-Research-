Baseline: Article-E1-LargeChunk-BM25

Ten retrieval questions are generated from each complete article before chunking. Each question is mapped to its supporting 1024-token chunk or chunks. Retrieval combines dense chunk vectors with mapped article-question vectors using 0.5/0.5 score fusion, then combines that ranking with BM25 chunk retrieval using reciprocal-rank fusion.

Candidate-pool size {20, 30, 44}, relevance weight {0.6, 0.7, 0.8}, and PCA variance threshold {80%, 90%, 95%} were selected using only the development split. Question filtering was disabled to isolate the retrieval-reranking effect. This is a spectral-geometry-inspired experiment, not a direct reproduction of a paper.

Geometry result: Spectral reranking produced the most diverse top-five evidence set, eliminating all four highly similar chunk pairs and reducing mean pairwise cosine from 0.620 to 0.551. It improved complementary multi-hop coverage (Full-evidence@5 0.706 → 0.765), Recall@10 (0.941 → 0.961), and MRR@10 (0.892 → 0.912), while slightly lowering Recall@5 (0.907 → 0.892). Cosine-MMR reduced redundancy but did not improve complementary evidence coverage.
