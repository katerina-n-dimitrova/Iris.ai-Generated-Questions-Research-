Protocol notes

IDs are namespaced with mhrag:: and yettel::, preventing collisions. Existing question generations and embeddings were reused exactly; no combined evaluation query was used as enrichment text. Metrics are computed against one common 2,793-chunk index, so distractors from both domains are present. Answer accuracy is not reported here because these four runs evaluate retrieval, not answer generation. The Yettel evaluation and enrichment questions were generated independently but by the same model, so same-model stylistic coupling remains a benchmark limitation.
